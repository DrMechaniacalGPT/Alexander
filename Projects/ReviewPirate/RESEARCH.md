# Research Standard

the research is the product

if this is shallow
the video is just another listicle
with a pirate hat

## target depth

before a flagship episode is scripted

aim for

- 25 to 50 meaningful sources
- multiple independent testing methodologies
- multiple YouTube reviewers
- professional written reviews
- manufacturer documentation
- long-term owner evidence
- support / reliability evidence when relevant

more sources
is not automatically better

twenty copied press releases
count as one bad source

## source classes

### primary product facts

manufacturer documentation
manuals
support pages
release notes
regulatory filings where useful

good for

what the product claims to do

bad for

whether it does it well

### controlled testing

reviewers
labs
and publications
that test products systematically

record

- what was measured
- protocol
- comparison set
- sample limitations
- whether the unit was purchased or supplied

### firsthand reviewers

useful for

- ergonomics
- setup
- software
- daily annoyances
- qualitative differences

record duration of use

launch-day impressions
and six-month ownership
are different evidence

### owners

forums
Reddit
retailer reviews
support communities

best for discovering

- failure modes
- reliability
- recurring bugs
- support quality
- weird edge cases

terrible for estimating prevalence
without a denominator

### secondary summaries

useful for discovery

do not let
someone else's synthesis
silently become ours

## claim ledger

for every important claim record

- exact claim
- product / version
- source
- date
- evidence type
- direct observation or inference
- method if measured
- source incentives
- support / contradiction / qualification
- confidence
- notes

## coverage matrix

for every episode

build a source-product matrix

record

- source
- product
- substantive coverage
- depth
- verdict direction
- evidence link
- date

blank cells
must remain blank

do not infer

not reviewed

as

negative

the matrix
is both

a research QA tool

and

a recurring visual asset

## incentives

for every professional source
also record

- bought / supplied / loaned / unknown
- sponsored / not sponsored / unknown
- affiliate route
- direct-brand affiliate if verified
- publisher versus personal incentive
- editorial-firewall policy
- evidence for each field

for brands

record public
affiliate economics

but never assume

a reviewer participates
in a public program

or receives
the headline rate

possible incentive

is not

proven influence

over time

test relationships
between

coverage
recommendations
and economics

instead of
assigning
a vibes-based bias score

## independence

five sources
can still be one source

watch for

- copied manufacturer language
- repeated benchmark numbers
- syndicated articles
- creators citing the same original test
- press-embargo talking points
- affiliate sites with no evidence of possession

the goal is not
to accuse everyone of corruption

the goal is to avoid
counting echoes as consensus

## disagreement

never average away
an interesting disagreement

ask

- did they test different firmware
- different floor types
- different products with similar names
- different price points
- different use cases
- different test protocols
- short-term versus long-term use
- different definitions of "best"

the hidden variable
is often the story

## reviewer review

Review Pirate should also review the reviewers

over time track

- what each source measures well
- recurring blind spots
- disclosed commercial relationships
- whether recommendations age well
- which claims later prove wrong
- which reviewers disagree predictably

this becomes
part of the long-term research moat

## corrections

facts change

firmware changes
prices change
products disappear

keep a dated source ledger

if an episode becomes materially wrong
correct the description
pin a correction
or make the update the next story

trust compounds
when mistakes are allowed to exist
and required to be repaired
