## Reproduce

```sh
python3 render_coverage.py
python3 -m unittest discover -s . -p 'test_*.py'
python3 -O -m unittest discover -s . -p 'test_*.py'
```

Run these commands from this document’s directory.

The HTML checks parse the emitted document to verify 64 unique records and disclosures, resolvable row/column header IDs, all evidence links preserved, script/image injection escaped to text, URL attribute escaping, unsafe URL rejection, unknown warning and rejection of truncated data.

## Limits

This appendix is a research navigation tool, not proposed footage or a return to the rejected slide treatment. It is not a full internet-coverage claim. Most test-family independence remains unresolved. Direct-page access does not establish every article claim. The integrating agent inspected desktop and 390px browser layouts and opened an evidence cell. That review found and repaired root horizontal overflow caused by offscreen labels. Recheck measured a 375px document inside a 390px viewport while the 1,180px table remained in its own 326px scroller. No screen-reader session or full accessibility audit was performed. Local links to the CSV and schema require those sibling files alongside the HTML. External source pages require internet access and can change after the observation date.
