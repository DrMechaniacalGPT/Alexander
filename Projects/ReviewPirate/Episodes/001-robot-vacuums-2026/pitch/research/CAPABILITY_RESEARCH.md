## Critique of the recommendation

The strongest inspected animal evidence is Veo's raccoon, so a categorical claim that Seedance/Higgsfield is visually best would be unjustified. The case for Higgsfield is broad experimentation and art-direction controls, plus the owner's expressed interest. The free Flow route may be sufficient for first proof and should precede buying another tool when account access permits.

Native sound is attractive but not a solution to narration quality by itself. Veo's own [limitations](https://deepmind.google/models/veo/#limitations) acknowledge natural/consistent short speech remains under development. Test one plain line, not a model-name-heavy paragraph. Build atmosphere separately from factual narration if needed. Every final spoken line needs an actual listening reviewer; visual screenshots, transcripts and waveform checks cannot approve delivery.

An otter should behave like a composed adult guide, not a baby mascot. One understated reaction is enough. A useful no-host control uses identical script and home: voiceover plus camera movement, textured household detail and precise editorial overlays. If the character adds charm but weakens trust or clarity, retain the cinematic world and remove the host. Do not substitute mediocre character footage just because we spent credits generating it.

Our conceptual home is a stage for explanation, not a pretend independent test lab. Use generic illustrative devices in generated action; exact product representations and factual comparisons must remain faithful, sourced and separately controlled. No shot of invented debris removal, obstacle avoidance or pet-hair success should be presented as measured evidence.

## Test acceptance checklist

1. Freeze approved room, light direction, character proportions and costume before video requests.
2. Same three shot briefs across two routes; three attempts per shot maximum before diagnosis. Save failures.
3. Inspect full clips for identity, paw/face anatomy, product drift, floor contact, shadows and transient defects. A good first frame is insufficient.
4. Review speech by listening. Reject unnatural stress, garbled names, waxy lip-sync or distracting sound.
5. The 12-second edit must communicate a useful point without a character introduction or brand bumper.
6. Only accepted shots enter the owner preview. When no take meets the bar, report what failed and show the best reference/pitch instead of delivering a knowingly bad sample.

### Omni changes the experiment, not the quality bar

[Current Flow features](https://support.google.com/flow/answer/16352836?hl=en): Omni Flash 1.1 supports 4/6/8/10-second reference generations, first/last frames and video edits up to ten seconds; all users can access it in supported regions. Some voice features vary by region. Flow extension is still coming soon.

The [creation guide](https://support.google.com/flow/answer/16353334?hl=en) documents voice presets and custom styling with sample dialogue. Voice references attach to Ingredients generation, not every input mode. This could address voice consistency without another service immediately, but animal lip-sync and performance still need listening and motion review.

The [Omni API guide](https://ai.google.dev/gemini-api/docs/omni) recommends explicit continuous-shot instructions when cuts are unwanted. Simple local edits are preferable to complex changes that may disturb other elements. Video references ignore audio and uploaded audio references are unsupported. API extension can produce longer sequences but uses limited recent context; its availability is not Flow web availability. Do not advertise unlimited consistent-character movies.

**Exploratory cross-model allocation (not the selected first test):** one 6-second room shot, one 6-second host performance and one 6-second reverse angle at Omni 720p = 30 credits; one 8-second Veo Fast comparator = 20. This fits the documented 50 daily credits if each request produces one output. It leaves no room for reference generation or retries that day. Existing approved references must be available, and required uploads authorized.

**Paid arithmetic scenario (allocation refined in MOTION_TEST.md):** nine Omni 6-second attempts = 90 credits, three Veo Fast comparators = 60, two Omni edit attempts = 80, subtotal 230, plus quoted reference/voice preparation. Fits Pro's 1,000 monthly allowance. These are arithmetic scenarios from [Flow's credit table](https://support.google.com/flow/answer/16526234?hl=en), not yield predictions. A 40-credit edit costs four fresh six-second Omni generations: reserve edits for near-keepers with a local defect. No need to begin with Ultra.

### Revised judgment

The strongest visually inspected animal evidence remains Veo's raccoon; Omni's case is current reference controls, integrated voice styling and inexpensive iteration. Testing both within Flow is now more justified than immediately purchasing another platform. Higgsfield is next if a concrete failure merits Seedance/Kling comparison.

Research supports a credible cinematic route and controlled experiment. It cannot select the final host, guarantee appealing speech, rank every latest model or promise exact product geometry. The next useful work is an approved-look shot test, not an undirected catalogue of tools. If every take fails, deliver the storyboard, reference films, defect log and next experiment rather than a poor montage.
