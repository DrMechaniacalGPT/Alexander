# Small party transfer test

Original four-player museum party, authored for this iteration before inference. One group introduction per player, then two reliable host clue cards and private assessments. Four combinations of two binary attributes produce exactly one jointly matching character. Pet/badge facts must be truthful and shareable; culprit involvement is private. This tests a deliberately sufficient, simple party context, not natural freeform deception or human enjoyment.

Offline rubric: introductions preserve own pet/access and avoid borrowing facts or revealing involvement. A nonculprit final answer identifies the unique matching character with both attributes attributed to the correct person. A correct name without both supporting facts is partial. Wrong ownership, contradiction, unsupported added events, or failure to use a genuinely delivered attribute is a failure. If a model failed to share a required attribute, distinguish the resulting incomplete context. The culprit's privileged answer is excluded from nonculprit deduction counts.

Expected evaluator answer is stored only in the case truth and this offline description's structure; the runner does not send truth to players. Intended positive result is three coherent, supported nonculprit answers. Freeze the fixture before comparing installed models; retain negative outputs.

A separately frozen transfer variant, `05_museum_party_shifted.json`, changes one host clue and the corresponding private culprit assignment while keeping the public cast/attribute introductions unchanged. It checks that the result follows the clue conjunction rather than repeating the original suspect. It is not a repair of the original result.
